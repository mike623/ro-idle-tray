### 2026-11-04 · p6.45 — MVP 改回每個隊伍一個世界、南門聊天室可以用經典表情與擲骰子

- MVP 改回全服共享之前的方式：每個隊伍一個世界，重生時間每隻角色各自計算，同隊在同一張地圖的隊員共用；別人打倒不影響你，不用跟其他隊伍搶。改回的原因：全服共享的 MVP 只有開著遊戲、正在即時結算的角色遇得到；要讓沒開遊戲的掛機角色也一起搶，伺服器就得隨時即時模擬所有離線角色，運算量會多好幾倍，主機負擔不了。改回各自的世界後，沒開遊戲的掛機角色回來補進度時也會遇到 MVP（離線很久的那段時間除外）。已經打倒、還沒領的全服 MVP 獎勵照樣會發；還沒被打倒的那幾隻全服 MVP 不再出現，打過的傷害不計。「社群 → 全服 MVP」頁面與「地點與目標」的全服血條一併收起。（使用者決定）
- 南門聊天室可以用原版的經典表情：聊天欄按「表情」點一個，或直接輸入台版的指令（例如 /！、/？、/高興、/愛心、/感謝、/e1～/e12，共 51 個），頭上會播表情動畫，聊天紀錄顯示小圖；其他頻道輸入表情指令也會顯示成小圖。/石頭、/剪刀、/布 可以猜拳；按「擲骰子」或輸入 /骰子 由伺服器擲出 1～6 點，大家看到的點數都一樣，不能自己指定。（使用者規劃）
